ZenLab

ZenLab is a small personal tool used by the owner of the ZenLab social media accounts (YouTube @ZenLabCore, Instagram @zenlabcore, TikTok @zenlab4) to edit and publish their own short video clips to their own accounts.

It is not offered to the public and has no other users. It uses the official YouTube Data API, Instagram API and TikTok Content Posting API only to upload videos that the account owner created and approved.
